# mapsmith — dev notes

New project, created 2026-10-21. Public MIT tool extracted (clean-room) from the
`khabar-bd` Google-Maps scraping engine and re-scoped as a reusable, config-driven
scraper with menu-tab capture.

## Why it exists

Answering "is my scraper better than `gosom/google-maps-scraper`?" — the honest
answer was: *different*. gosom wins on throughput/proxies/Docker; the khabar
engine had three things gosom lacks (menu-tab photos+text, ultra-light headless
mode, per-place-per-step resume). So the right move was not "merge", it was
"publish the parts that are genuinely better, as a small library".

## Measured facts (2026-10-21)

- Playwright lives in `~/tools/Ai-Browser-Toolkit/.venv` on this box (the `py`
  wrapper’s venv); system Chrome 155 and `chromium_headless_shell-1243` exist.
- Live smoke: `list` for "tea stall in Bogura" → **110 places** in one query;
  detail found rating/phone/category/photos; menu returned empty (correct — no
  Menu tab).
- **Locale trap:** opening a bare `/maps/place/…` URL geo-serves a **Bangla** UI
  (`এক নজরে / রিভিউ / সম্পর্কে`) and every English selector misses. Going through a
  search (`?hl=en`) makes the whole session English (`Overview / Reviews / About`).
  Always drive from `list` first.
- **Playwright bug:** `page.evaluate(..., timeout=…)` raises `TypeError` (no such
  kwarg) and was being swallowed to `None` → 0 results with no error. Removed.
- **Menu tab is mostly gone** in current Google Maps (only Overview/Reviews/About
  tabs on the sampled Dhanmondi/Bogura places). `menu_images` empty is normal;
  khabar's 24-menu-image capture predates the UI change or used a different path.
- Export verified: 4 files, 117 rows into SQLite, 5/5 unit tests pass.

## Status

- Verified working: list, detail, reviews, menu (empty-when-absent), export,
  queue, resume markers, CLI, package import.
- Not implemented (documented as limitations): proxy rotation, grid/bbox coverage,
  concurrent browser fan-out beyond threaded pages.
